#  Travel inSights USA – Tourism Analytics Platform

## Overview
Travel inSights USA is a data-driven tourism analytics project that integrates airline traffic data and traveler sentiment analysis to uncover seasonal demand trends and high-growth destinations across the United States.

## This project was designed to:

-Identify which stakeholders benefit most from tourism analytics insights
-Determine optimal travel seasons using airline traffic trends

## Tools Used
- Excel (data cleaning, modeling, preprocessing)
- Classification models (k-NN, Naive Bayes, Decision Tree) to analyze airline traffic patterns.
- Trend and seasonal analysis
- Sentiment analysis

## Key Insights
- Higher flight volume correlates with increased profitability.
- Seasonal patterns significantly influence domestic travel demand.
- Sentiment analysis identifies under-promoted but highly rated destinations.
